# Screenshot placeholders

Add sanitized screenshots with these names before publishing internal documentation:

* `github-environments.png` — environment variables and protection rules, with IDs redacted.
* `workflow-promotion.png` — successful dev-to-test promotion.
* `sql-networking.png` — SQL networking page showing no permanent firewall rules.

Never capture tokens, tenant identifiers, subscription identifiers, IP addresses, or production resource names.
